# 🍔 Swiggy Sales Dashboard - Excel Project

An interactive sales analysis dashboard built in **Microsoft Excel** to analyze Swiggy food delivery data across India.

## 📌 Project Overview
This project visualizes Swiggy's sales performance across different dimensions like Food Type, Restaurant, City, State, Month, and Day.

## 🎯 Objectives
- Analyze Month-wise & Day-wise sales trends
- Compare Veg vs Non-Veg food type sales
- Identify Top 5 Cities & Top Restaurants by sales
- Visualize State-wise sales distribution on India Map
- Enable dynamic filtering using Slicers

## 📊 Dataset Used
Columns: Order ID, Food Type, Restaurant Name, City, State, Order Date, Month, Day Name, Sales

States Covered: Rajasthan (1317), Telangana (983), Delhi (882), Gujarat (863), Goa (815), UP (691), Tamil Nadu (553), Bihar (417), Assam (405), Karnataka (403), West Bengal (163)

## 🛠️ Tools & Features Used
- Microsoft Excel (Pivot Tables & Pivot Charts)
- Slicers: Food Type, Restaurant, City, State, Month
- Charts:
    - Line Chart - Month wise trend
    - Donut Chart - Food Type Sales
    - Bar Chart - Day wise & City wise sales
    - Column Chart - Restaurant wise sales
    - India Map - State wise sales (Orange Gradient #FF6F00)

## 📈 Key Insights
1. Rajasthan (1317) has highest sales
2. Non-Veg (67%) dominates over Veg
3. Monday & Saturday = highest sales
4. Kolkata & Ahmedabad are top cities
5. April & July = peak months

## 🖥️ Dashboard Layout
[Filters Row] -> [Trend | Food Type | India Map] -> [Day wise | City wise] -> [Restaurant wise]

## 🚀 How to Use
1. Open Swiggy_Sales_Dashboard.xlsx
2. Use Slicers on top to filter
3. Charts auto-update dynamically
